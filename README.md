# Portfolio de desarrollo web · Mariano Yuffa

Selección de proyectos académicos realizados durante mi formación en desarrollo web. Cada proyecto es un sitio estático (sin servidor ni base de datos).

**Portfolio publicado:** https://marianoyuffa.github.io/proyectos-finales-web/

## Proyectos

### Clases de portugués (febrero de 2026)

Sitio multipágina para presentar clases de portugués para principiantes.

- **Ver sitio:** https://marianoyuffa.github.io/proyectos-finales-web/Clases/index.html
- **Código:** carpeta [`Clases`](Clases)
- **Tecnologías:** HTML5 y Bootstrap 5.3.2
- **Qué incluye:** barra de navegación responsive, carrusel de imágenes, pestañas de metodología, diseño en columnas y formulario de contacto.
- **Alcance:** el formulario es una demostración y no envía datos.

### Museos de Ciudad de México (diciembre de 2024)

Guía informativa sobre el Museo Nacional de Antropología, el Museo de Historia Natural, el Papalote Museo del Niño y Universum.

- **Ver sitio:** https://marianoyuffa.github.io/proyectos-finales-web/ProyectoMuseos/index.html
- **Código:** carpeta [`ProyectoMuseos`](ProyectoMuseos)
- **Tecnologías:** HTML5 y CSS3, con una hoja de estilos compartida
- **Qué incluye:** navegación multipágina, contenido en columnas que pasa a una sola columna en pantallas angostas e imágenes con texto alternativo.
- **Alcance:** la información (exposiciones, horarios y precios) fue relevada en diciembre de 2024 y puede haber cambiado.

## Accesibilidad

Aplico prácticas básicas de accesibilidad web y reviso mis páginas con el lector de pantalla NVDA:

- Enlace para saltar al contenido principal en todas las páginas.
- Estructura semántica con encabezados ordenados y regiones (`header`, `nav`, `main`, `footer`).
- Texto alternativo en las imágenes, incluido el texto de las imágenes que contienen texto.
- Formularios con etiquetas asociadas a cada campo.
- Emojis decorativos ocultos a los lectores de pantalla.
- Indicador de foco visible en los enlaces y botones.

Es un trabajo en progreso: no son sitios auditados con una conformidad WCAG certificada.
